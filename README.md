# Hydra

Hydra é um projeto de linguagem de programação em fase de definição arquitetural.

## Estado do projeto

- **HYDRA-000 — Fundação e auditoria arquitetural:** pendente de execução e aprovação.
- Sintaxe, semântica, arquitetura e targets ainda não foram aprovados.
- Nenhum compilador Hydra foi implementado neste repositório.

## Repositório de referência

O [Kof4j](https://github.com/KofLang/Kof4j) será estudado como referência arquitetural, respeitando sua licença GPL-3.0. Seu código-fonte não faz parte deste repositório e a Hydra não presume compatibilidade com ele.

## Governança

O desenvolvimento será organizado em fases com entregáveis, critérios objetivos de aceitação, evidências verificáveis e aprovação humana antes de avançar.
